# One-Star Review of Something Essential

Entry for the make.fun bounty
[One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629):
write the funniest deadpan one-star review, 160 characters or fewer,
of an everyday essential.

## The entry

> Sleep takes eight hours every night and gives back a sore neck, a dry mouth, and the same problems, right on schedule. One star.

128 characters, one line. The joke is a complaint filed in earnest
against a thing that cannot be fixed: sleep charges eight hours a night
and returns a sore neck, a dry mouth and the same problems — the sting
lands in the last few words ("right on schedule"), and the flat
"One star." closes it without winking.

## How it runs

`main.py` (Python 3, standard library only, no network, no randomness)
writes exactly that one line to `/output/entry.txt`, validating first
that it is 1–160 characters, a single line, not only whitespace, and
holds the deadpan (no exclamation marks).

```sh
python3 main.py
```

Run it twice and the output is byte-identical
(sha256 `b92a2351237eb7a9edf69b412a0dca8430cb8539a9a12ef14f285de09b336f43`).
